## 🎓 Как использовать курс

### Для начинающих:
1. **Установите компилятор** (см. раздел "Быстрый старт")
2. **Запустите главное меню**: `ГЛАВНОЕ_МЕНЮ.bat`
3. **Начните с раздела "Основы"**
4. **Изучайте последовательно** - каждый урок строится на предыдущем
5. **Выполняйте задания** в конце каждого файла

### Для продолжающих:
1. Выберите интересующий раздел
2. Изучите примеры с `.h` файлами
3. Попробуйте игры
4. Модифицируйте код под свои задачи

### Рекомендуемый путь:
```
01_Основы → 02_Управляющие_конструкции → 03_Функции → 
04_Массивы_и_строки → Игра "Угадай число" → 
05_Указатели_и_ссылки → 06_ООП → Игра "Крестики-нолики" → 
07_STL → 08_Файлы → 09_Продвинутые_темы → Все игры
```

## Компиляция и запуск

### Быстрый старт

**Windows:**
```cmd
g++ 01_Основы\01_hello_world.cpp -o hello.exe
hello.exe
```

**Linux/macOS:**
```bash
g++ 01_Основы/01_hello_world.cpp -o hello
./hello
```

📖 **Подробная инструкция:** см. файл `КАК_КОМПИЛИРОВАТЬ.md`

## Важно: Кодировка

Все файлы уже содержат код для корректного отображения русского текста в Windows:
```cpp
#include <windows.h>
SetConsoleOutputCP(CP_UTF8);
SetConsoleCP(CP_UTF8);
```

Если видите кракозябры, убедитесь что:
1. Файл сохранен в UTF-8
2. Код выше присутствует в начале main()

## 🚀 Быстрый старт

### 1. Установите компилятор

**Windows (MSYS2 - рекомендуется):**
```bash
# Скачайте с https://www.msys2.org/
# После установки выполните:
pacman -Syu
pacman -S mingw-w64-x86_64-gcc
```

Добавьте `C:\msys64\mingw64\bin` в PATH.

**Linux:**
```bash
sudo apt install g++  # Ubuntu/Debian
```

**macOS:**
```bash
xcode-select --install
```

### 2. Проверьте установку

```cmd
ПРОВЕРКА_G++.bat
```

### 3. Компилируйте любой урок

```cmd
КОМПИЛИРОВАТЬ_УРОК.bat
```

Или вручную:
```bash
g++ 01_Основы/01_hello_world.cpp -o hello.exe
.\hello.exe
```

### 4. Главное меню (все функции)

```cmd
ГЛАВНОЕ_МЕНЮ.bat
```

Интерактивное меню для:
- ✅ Проверки компилятора
- ✅ Компиляции любого урока
- ✅ Тестирования
- ✅ Запуска примеров

## 🔧 Решение проблем

### ⚡ g++ не найден, но установлен?

**Быстрое решение:**
1. Закройте VS Code полностью
2. Откройте заново
3. Проверьте: `g++ --version`

**Или запустите:**
```cmd
ПРОВЕРКА_G++.bat
```

Подробнее: `БЫСТРОЕ_РЕШЕНИЕ.md`

### 🔍 Полная диагностика:
```powershell
.\ПРОВЕРКА_УСТАНОВКИ.ps1
```

### 📚 Все проблемы:
См. `РЕШЕНИЕ_ПРОБЛЕМ.md`:
- Компилятор не найден
