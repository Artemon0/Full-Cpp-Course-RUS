# 🔧 Решение частых проблем

## ❌ Проблема 1: "g++ не является внутренней или внешней командой"

### Что это значит?
Компилятор C++ не установлен или не добавлен в PATH.

### Решение:

#### Вариант 1: MSYS2 (рекомендуется для Windows)

**Шаг 1: Скачайте MSYS2**
- Перейдите на https://www.msys2.org/
- Скачайте установщик
- Запустите установку

**Шаг 2: Установите компилятор**
Откройте MSYS2 и выполните:
```bash
pacman -Syu
pacman -S mingw-w64-x86_64-gcc
```

**Шаг 3: Добавьте в PATH**
1. Откройте "Параметры системы" → "Дополнительные параметры системы"
2. Нажмите "Переменные среды"
3. В "Системные переменные" найдите `Path`
4. Нажмите "Изменить"
5. Добавьте: `C:\msys64\mingw64\bin`
6. Нажмите "ОК" везде

**Шаг 4: Перезапустите терминал**
Закройте и откройте заново VS Code или командную строку.

**Шаг 5: Проверьте**
```cmd
g++ --version
```

Должна появиться версия компилятора.

#### Вариант 2: MinGW-w64

**Шаг 1: Скачайте**
- https://sourceforge.net/projects/mingw-w64/

**Шаг 2: Установите**
- Выберите архитектуру: x86_64
- Threads: posix
- Exception: seh

**Шаг 3: Добавьте в PATH**
Добавьте путь к папке `bin` (например: `C:\mingw64\bin`)

#### Вариант 3: Visual Studio

**Шаг 1: Скачайте Visual Studio Community**
- https://visualstudio.microsoft.com/

**Шаг 2: При установке выберите**
- "Desktop development with C++"

**Шаг 3: Используйте Developer Command Prompt**
Вместо обычной командной строки используйте "Developer Command Prompt for VS"

## ❌ Проблема 3: Ошибка "undefined reference to..."

### Пример:
```
undefined reference to `add(int, int)'
```

### Причина:
Забыли подключить `.cpp` файл при компиляции.

### Решение:

**Неправильно:**
```bash
g++ main.cpp -o program
```

**Правильно:**
```bash
g++ main.cpp math.cpp -o program
```

Нужно указать **все** `.cpp` файлы!

---

## ❌ Проблема 4: Ошибка "redefinition of..."

### Пример:
```
error: redefinition of 'int add(int, int)'
```

### Причина:
Забыли include guards в `.h` файле.

### Решение:

**Неправильно:**
```cpp
// math.h
int add(int a, int b);
```

**Правильно:**
```cpp
// math.h
#ifndef MATH_H
#define MATH_H

int add(int a, int b);

#endif
```

## ❌ Проблема 5: Ошибка "file not found"

### Пример:
```
fatal error: math.h: No such file or directory
```

### Причина:
Неправильный путь к файлу.

### Решение:

**Для своих файлов используйте кавычки:**
```cpp
#include "math.h"      // ✅ Правильно
#include <math.h>      // ❌ Неправильно (это системный заголовок)
```

**Для системных файлов используйте угловые скобки:**
```cpp
#include <iostream>    // ✅ Правильно
#include "iostream"    // ❌ Неправильно
```

## ❌ Проблема 6: Программа не запускается

### Причина 1: Не скомпилировалась

Проверьте, что компиляция прошла без ошибок:
```bash
g++ main.cpp -o program
echo %ERRORLEVEL%  # Должно быть 0
```

### Причина 2: Неправильный путь

**Windows:**
```cmd
.\program.exe      # ✅ Правильно
program.exe        # ⚠️ Может не работать
program            # ❌ Неправильно
```

**Linux/macOS:**
```bash
./program          # ✅ Правильно
program            # ❌ Неправильно
```

## ❌ Проблема 7: Ошибки в VS Code

### "C++ extension is not installed"

**Решение:**
1. Откройте Extensions (Ctrl+Shift+X)
2. Найдите "C/C++"
3. Установите расширение от Microsoft

### "IntelliSense: #include errors detected"

**Решение:**
1. Нажмите Ctrl+Shift+P
2. Введите "C/C++: Edit Configurations"
3. Добавьте пути к компилятору

## 🔍 Диагностика проблем

### Проверка 1: Компилятор установлен?
```cmd
g++ --version
```

Должна появиться версия. Если нет - см. "Проблема 1".

### Проверка 2: Файлы на месте?
```cmd
dir *.cpp *.h
```

Должны быть видны все файлы проекта.

### Проверка 3: Кодировка правильная?
```cmd
chcp
```

Должно быть `65001` (UTF-8) или выполните `chcp 65001`.

### Проверка 4: Права доступа?
Убедитесь, что у вас есть права на запись в папку проекта.
