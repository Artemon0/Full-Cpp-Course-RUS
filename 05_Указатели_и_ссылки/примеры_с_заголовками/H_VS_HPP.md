# .h vs .hpp - Краткая шпаргалка

## 🎯 Главное

**Технически разницы НЕТ!** Оба работают одинаково. Это только соглашение об именовании.

---

## 📊 Быстрое сравнение

| Критерий | .h | .hpp |
|----------|----|----- |
| **Работает в C++?** | ✅ Да | ✅ Да |
| **Работает в C?** | ✅ Да | ❌ Нет* |
| **Традиционность** | ✅✅✅ Очень | ⚠️ Средне |
| **Популярность** | ✅✅✅ Высокая | ⚠️ Средняя |
| **Явность (это C++)** | ❌ Нет | ✅ Да |

*Технически может, но подразумевается C++ код

---

## 🤔 Когда использовать

### Используйте `.h` если:
```
✅ Совместимость с C и C++
✅ Традиционный подход
✅ Большинство проектов
✅ Не хотите думать о выборе
```

### Используйте `.hpp` если:
```
✅ Только C++ код
✅ Хотите явно показать "это C++"
✅ Проект уже использует .hpp
✅ Отделяете C от C++ в одном проекте
```

## 💡 Примеры из реальных проектов

### Используют .h:
- **Qt** - `QWidget.h`
- **OpenGL** - `gl.h`
- **SDL** - `SDL.h`
- **Windows API** - `windows.h`

### Используют .hpp:
- **Boost** - `boost/algorithm.hpp`
- **Некоторые современные библиотеки**

### Без расширения:
- **STL** - `<iostream>`, `<vector>`, `<string>`

---

## 📝 Примеры кода

### Вариант 1: .h
```cpp
// math.h
#ifndef MATH_H
#define MATH_H

int add(int a, int b);

#endif
```

### Вариант 2: .hpp
```cpp
// math.hpp
#ifndef MATH_HPP
#define MATH_HPP

int add(int a, int b);

#endif
```

### Компиляция (одинаково!)
```bash
# С .h
g++ main.cpp math.cpp -o program

# С .hpp
g++ main.cpp math.cpp -o program
```

---

## 🎨 Другие расширения (редко)

- `.hh` - альтернатива .hpp
- `.hxx` - еще одна альтернатива
- `.h++` - старое обозначение C++
- `.H` - с заглавной буквы

**Не рекомендуется использовать!** Придерживайтесь .h или .hpp

---

## ⚡ Быстрые факты

1. **Компилятору все равно** - оба работают одинаково
2. **Стандарта нет** - выбирайте сами
3. **Консистентность важнее** - используйте один стиль в проекте
4. **Большинство использует .h** - это безопасный выбор
5. **STL без расширений** - `<iostream>`, не `<iostream.h>`

---

## 🎓 Рекомендация для начинающих

**Используйте `.h`** потому что:
- ✅ Самое распространенное
- ✅ Работает везде
- ✅ Все примеры в интернете
- ✅ Проще запомнить

---

## 🚀 Правило золотое

> **Выберите один стиль и используйте его везде!**

Плохо:
```
project/
├── math.h
├── geometry.hpp  ← Смешивание стилей
└── physics.h
```

Хорошо:
```
project/
├── math.h
├── geometry.h    ← Единый стиль
└── physics.h
```
