# Пример с .hpp расширением

## Что это?

Это **точно такой же** пример Calculator, но с расширением `.hpp` вместо `.h`.

## В чем разница?

### Технически
**НИКАКОЙ!** Оба работают одинаково.

### Визуально
```
Calculator.h   ← традиционное расширение
Calculator.hpp ← C++ специфичное расширение
```

## Компиляция

Компилируется **точно так же**:

```bash
# С .h файлами
g++ main.cpp Calculator.cpp -o calculator

# С .hpp файлами
g++ main.cpp Calculator.cpp -o calculator_hpp
```

Компилятору все равно, какое расширение!

## Когда использовать .hpp?

### ✅ Используйте .hpp если:
- Пишете чисто C++ код
- Хотите явно показать, что это C++
- В проекте уже используется .hpp
- Хотите отделить C++ от C заголовков

### ✅ Используйте .h если:
- Нужна совместимость с C
- В проекте используется .h
- Следуете традициям
- Не хотите думать о выборе

## Сравнение файлов

### Calculator.h (из основной папки)
```cpp
#ifndef CALCULATOR_H
#define CALCULATOR_H

class Calculator {
    // ...
};

#endif
```

### Calculator.hpp (этот пример)
```cpp
#ifndef CALCULATOR_HPP
#define CALCULATOR_HPP

class Calculator {
    // ...
};

#endif
```

**Единственная разница:** имя в include guard и расширение файла!

## Вывод

🎯 **Главное:** Выберите один стиль и используйте его везде в проекте!

Оба варианта правильные. Консистентность важнее выбора конкретного расширения.
