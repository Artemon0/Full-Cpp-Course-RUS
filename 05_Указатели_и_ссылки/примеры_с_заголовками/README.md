# Примеры с заголовочными файлами

Эта папка содержит примеры правильной организации кода с использованием `.h` и `.cpp` файлов.

## Структура проекта

### 📁 Пример 1: Модуль математических функций (простой)
- `math.h` - объявления функций
- `math.cpp` - реализация функций
- `main.cpp` - использование модуля

**Уровень:** Начинающий  
**Концепции:** Базовое разделение на .h и .cpp

### 📁 Пример 2: Класс Student (средний)
- `Student.h` - объявление класса
- `Student.cpp` - реализация методов класса
- `main_student.cpp` - использование класса

**Уровень:** Средний  
**Концепции:** Классы, инкапсуляция, геттеры/сеттеры

### 📁 Пример 3: Класс Calculator (продвинутый)
- `Calculator.h` - объявление класса с inline функциями
- `Calculator.cpp` - реализация методов
- `main_calculator.cpp` - использование класса

**Уровень:** Продвинутый  
**Концепции:** Конструктор/деструктор, inline функции, константы, глобальные функции

### 📁 Пример 4: Класс Array (эксперт)
- `Array.h` - объявление класса динамического массива
- `Array.cpp` - реализация с управлением памятью
- `main_array.cpp` - использование класса

**Уровень:** Эксперт  
**Концепции:** Динамическая память, конструктор копирования, перегрузка операторов, правило трех

### 📁 Бонус: Пример с .hpp расширением
- `example_hpp/` - тот же Calculator, но с .hpp вместо .h
- Демонстрирует, что .h и .hpp работают одинаково
- См. `H_VS_HPP.md` для подробностей

## Зачем нужны заголовочные файлы?

1. **Разделение интерфейса и реализации**
   - `.h` (или `.hpp`) файл показывает, ЧТО делает код
   - `.cpp` файл показывает, КАК это работает

2. **Переиспользование кода**
   - Один модуль можно использовать в разных проектах
   - Достаточно подключить заголовочный файл

3. **Ускорение компиляции**
   - Изменения в `.cpp` не требуют перекомпиляции всего проекта
   - Компилятор может кэшировать заголовки

4. **Работа в команде**
   - Разные программисты работают над разными модулями
   - Заголовки служат документацией

## .h vs .hpp

**Краткий ответ:** Технически никакой разницы! Оба работают одинаково.

- `.h` - традиционное расширение (используется в этом курсе)
- `.hpp` - явно указывает на C++ код

📖 **Подробнее:** см. `H_VS_HPP.md` и `example_hpp/`

## Include Guards

```cpp
#ifndef ФАЙЛ_H
#define ФАЙЛ_H

// Код заголовочного файла

#endif
```

Защита от множественного включения - предотвращает ошибки при повторном подключении файла.

## Советы

- Всегда используйте include guards в `.h` файлах
- Объявляйте только интерфейс в `.h`, реализацию в `.cpp`
- Используйте `const` для методов, которые не изменяют объект
- Группируйте связанные функции в один модуль
