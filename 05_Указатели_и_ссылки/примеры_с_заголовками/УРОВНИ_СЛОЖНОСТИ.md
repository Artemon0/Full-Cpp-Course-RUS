# 📚 Примеры с заголовочными файлами - Уровни сложности

Эта папка содержит примеры работы с `.h` файлами от простого к сложному.

---

## 🎯 Уровень 1: Простые функции (★☆☆☆☆)

### Файлы: `math.h` + `math.cpp` + `main.cpp`

**Что изучаем:**
- Базовое разделение на `.h` и `.cpp`
- Простые функции
- Include guards
- Компиляция нескольких файлов

**Сложность:** Для начинающих

**Пример использования:**
```cpp
#include "math.h"

int result = add(5, 3);        // 8
int result2 = multiply(4, 7);  // 28
```

**Компиляция:**
```bash
g++ main.cpp math.cpp -o example1
```

---

## 🎯 Уровень 2: Простой класс (★★☆☆☆)

### Файлы: `Student.h` + `Student.cpp` + `main_student.cpp`

**Что изучаем:**
- Класс в заголовочном файле
- Методы класса
- Конструкторы
- Геттеры и сеттеры
- Инкапсуляция (private/public)

**Сложность:** Базовый ООП

**Пример использования:**
```cpp
#include "Student.h"

Student student("Иван", 20, 4.5);
student.showInfo();
student.study();
```

**Компиляция:**
```bash
g++ main_student.cpp Student.cpp -o example2
```

---

## 🎯 Уровень 3: Класс с методами (★★★☆☆)

### Файлы: `Calculator.h` + `Calculator.cpp` + `main_calculator.cpp`

**Что изучаем:**
- Более сложный класс
- Множество методов
- Приватные данные (история операций)
- Методы работы с данными класса

**Сложность:** Средний

**Пример использования:**
```cpp
#include "Calculator.h"

Calculator calc;
calc.add(10);
calc.multiply(5);
calc.showHistory();  // История всех операций
```

**Компиляция:**
```bash
g++ main_calculator.cpp Calculator.cpp -o example3
```

---

## 🎯 Уровень 4: Продвинутый класс (★★★★☆)

### Файлы: `Array.h` + `Array.cpp` + `main_array.cpp`

**Что изучаем:**
- Управление динамической памятью
- Конструктор копирования
- Оператор присваивания
- Деструктор
- Перегрузка операторов
- Правило трех (Rule of Three)
- Автоматическое управление ресурсами

**Сложность:** Продвинутый

**Пример использования:**
```cpp
#include "Array.h"

Array arr;
arr.push_back(10);
arr.push_back(20);
arr.sort();
cout << "Сумма: " << arr.sum() << endl;
```

**Компиляция:**
```bash
g++ main_array.cpp Array.cpp -o example4
```
