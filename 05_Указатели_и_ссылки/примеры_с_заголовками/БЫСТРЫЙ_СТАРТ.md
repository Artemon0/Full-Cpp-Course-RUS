## 💡 Ключевые концепции

### Что такое .h файл?
Файл с **объявлениями** (что есть), но без **определений** (как работает).

### Зачем нужны .h файлы?
1. Разделение интерфейса и реализации
2. Переиспользование кода
3. Ускорение компиляции
4. Документация

### Базовая структура .h файла
```cpp
#ifndef FILENAME_H
#define FILENAME_H

// Объявления здесь

#endif
```

### Базовая структура .cpp файла
```cpp
#include "filename.h"

// Определения здесь
```

## 🔧 Компиляция

### Один файл
```bash
g++ main.cpp -o program
```

### Несколько файлов
```bash
g++ main.cpp module1.cpp module2.cpp -o program
```

### С предупреждениями
```bash
g++ -Wall -Wextra main.cpp module.cpp -o program
```

## ❓ Частые вопросы

### Q: Почему нельзя писать определения в .h?
**A:** Если .h подключить в несколько файлов, будет ошибка множественного определения.

### Q: Что такое include guards?
**A:** Защита от повторного включения файла:
```cpp
#ifndef FILENAME_H
#define FILENAME_H
// код
#endif
```

### Q: Когда использовать inline функции?
**A:** Для маленьких функций (1-3 строки), которые часто вызываются.

### Q: Что такое forward declaration?
**A:** Объявление класса без определения:
```cpp
class MyClass;  // Forward declaration
```

## 🐛 Решение проблем

### Ошибка: "undefined reference to..."
**Решение:** Забыли подключить .cpp файл при компиляции
```bash
g++ main.cpp module.cpp -o program  # Правильно
```

### Ошибка: "multiple definition of..."
**Решение:** Определение функции в .h файле или забыли include guards

### Ошибка: "file not found"
**Решение:** Неправильный путь к файлу
```cpp
#include "module.h"  // Для своих файлов
#include <iostream>  // Для системных
```
