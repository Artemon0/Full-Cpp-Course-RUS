Структура курса

📚 Теоретические разделы

  • 01. Основы - Hello World, переменные, операторы
  • 02. Управляющие конструкции - if/else, циклы, switch
  • 03. Функции - объявление, параметры, перегрузка
  • 04. Массивы и строки - работа с данными
  • 05. Указатели и ссылки - управление памятью, .h файлы
  • 06. ООП - классы, наследование, полиморфизм
  • 07. STL - vector, string, map
  • 08. Файлы - чтение и запись
  • 09. Продвинутые темы - шаблоны, исключения

🎮 Практические игры

  • Угадай число - простая игра для начинающих
  • Камень, ножницы, бумага - игра против компьютера
  • Виселица - угадывание слов по буквам
  • Крестики-нолики - классическая игра для двух игроков

Быстрый старт

1

Скачайте курс

Клонируйте репозиторий или скачайте ZIP архив

git clone https://github.com/Artemon0/Full-Cpp-Course-RUS.git
2

Установите компилятор

Установите MSYS2 и g++ (инструкция в КАК_КОМПИЛИРОВАТЬ.md)

pacman -S mingw-w64-x86_64-gcc
3

Запустите главное меню

Откройте ГЛАВНОЕ_МЕНЮ.bat и выберите урок

ГЛАВНОЕ_МЕНЮ.bat
4

Начните обучение

Изучайте материалы последовательно, выполняйте задания

КОМПИЛИРОВАТЬ_УРОК.bat

Присоединяйтесь к тысячам разработчиков, изучающих C++
