# Сайт курса C++

Этот сайт создан с помощью GitHub Pages.

## Просмотр локально

Откройте `index.html` в браузере.

## Структура

- `index.html` - главная страница
- `style.css` - стили
- `script.js` - JavaScript для анимаций

## Публикация

Сайт автоматически публикуется на GitHub Pages при push в main ветку.
