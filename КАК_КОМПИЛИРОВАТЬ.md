# Как компилировать и запускать программы

## Установка компилятора

### Windows

**Вариант 1: MinGW-w64**
1. Скачайте MinGW-w64: https://www.mingw-w64.org/downloads/
2. Установите и добавьте в PATH
3. Проверьте: `g++ --version`

**Вариант 2: MSYS2 (рекомендуется)**
1. Скачайте MSYS2: https://www.msys2.org/
2. Установите и запустите MSYS2
3. Выполните: `pacman -S mingw-w64-x86_64-gcc`
4. Добавьте `C:\msys64\mingw64\bin` в PATH

**Вариант 3: Visual Studio**
1. Скачайте Visual Studio Community
2. Установите "Desktop development with C++"

### Linux
```bash
sudo apt install g++  # Ubuntu/Debian
sudo yum install gcc-c++  # CentOS/RHEL
```

### macOS
```bash
xcode-select --install
```

## Компиляция и запуск

### Простой файл

**Windows (cmd):**
```cmd
g++ 01_Основы\01_hello_world.cpp -o hello.exe
hello.exe
```

**Windows (PowerShell):**
```powershell
g++ "01_Основы/01_hello_world.cpp" -o hello.exe
.\hello.exe
```

**Linux/macOS:**
```bash
g++ 01_Основы/01_hello_world.cpp -o hello
./hello
```

### Многофайловый проект

**Пример с заголовочными файлами:**

```bash
cd 05_Указатели_и_ссылки/примеры_с_заголовками

# Компиляция
g++ main.cpp math.cpp -o calculator

# Запуск
./calculator  # Linux/macOS
calculator.exe  # Windows
```

**Пример с классом Student:**

```bash
g++ main_student.cpp Student.cpp -o students
./students  # Linux/macOS
students.exe  # Windows
```

## Решение проблем с кодировкой

### Если видите кракозябры вместо русского текста:

**Все файлы уже содержат код для исправления кодировки:**
```cpp
#include <windows.h>

int main() {
    SetConsoleOutputCP(CP_UTF8);
    SetConsoleCP(CP_UTF8);
    // ... остальной код
}
```

**Альтернативный способ (через консоль):**
```cmd
chcp 65001
```

### Linux/macOS
Обычно проблем нет, но если есть:
```bash
export LANG=ru_RU.UTF-8
```

## Флаги компиляции

### Базовая компиляция
```bash
g++ program.cpp -o program
```

### С предупреждениями
```bash
g++ -Wall -Wextra program.cpp -o program
```

### С отладочной информацией
```bash
g++ -g program.cpp -o program
```

### С оптимизацией
```bash
g++ -O2 program.cpp -o program
```

### C++11/14/17/20
```bash
g++ -std=c++11 program.cpp -o program
g++ -std=c++17 program.cpp -o program
g++ -std=c++20 program.cpp -o program
```

## Использование IDE

### Visual Studio Code
1. Установите расширение "C/C++"
2. Создайте `tasks.json` для компиляции
3. Используйте F5 для запуска

### Code::Blocks
1. File → New → Project → Console Application
2. Добавьте файлы в проект
3. Build → Build and Run

### CLion
1. Откройте папку как проект
2. CLion автоматически создаст CMakeLists.txt
3. Используйте Shift+F10 для запуска

## Полезные команды

### Проверка версии компилятора
```bash
g++ --version
```

### Только компиляция (без линковки)
```bash
g++ -c file.cpp
```

### Просмотр предупреждений
```bash
g++ -Wall -Wextra -Wpedantic file.cpp
```

### Создание статической библиотеки
```bash
g++ -c math.cpp
ar rcs libmath.a math.o
g++ main.cpp -L. -lmath -o program
```

## Troubleshooting

### Ошибка: "g++ не является внутренней или внешней командой"
- Компилятор не установлен или не добавлен в PATH
- Решение: установите MinGW или MSYS2 и добавьте в PATH

### Ошибка: "undefined reference to..."
- Не все файлы скомпилированы вместе
- Решение: укажите все .cpp файлы при компиляции

### Кракозябры вместо русского текста
- Проблема с кодировкой консоли
- Решение: код уже содержит `SetConsoleOutputCP(CP_UTF8)`

### Программа не запускается
- Проверьте, что компиляция прошла без ошибок
- Убедитесь, что используете правильный путь к .exe файлу
