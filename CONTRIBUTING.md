## Как помочь проекту

### 🐛 Нашли ошибку?

1. Проверьте, нет ли уже [Issue](https://github.com/Artemon0/Full-Cpp-Course-RUS/issues) по этой проблеме
2. Создайте новый Issue с описанием:
   - Что не работает
   - Как воспроизвести
   - Ожидаемое поведение
   - Скриншоты (если применимо)

### 💡 Есть идея улучшения?

1. Создайте Issue с тегом "enhancement"
2. Опишите вашу идею
3. Объясните, почему это будет полезно

### 🔧 Хотите исправить ошибку или добавить функцию?

1. Fork репозитория
2. Создайте ветку: `git checkout -b fix/your-fix-name`
3. Внесите изменения
4. Commit: `git commit -m "Описание изменений"`
5. Push: `git push origin fix/your-fix-name`
6. Создайте Pull Request

## Стандарты кода

### Комментарии
- **Все комментарии на русском языке**
- Объясняйте "почему", а не "что"

### Имена переменных
- **Все имена на английском языке**
- Используйте camelCase для переменных: `studentName`
- Используйте PascalCase для классов: `StudentInfo`
- Используйте UPPER_CASE для констант: `MAX_SIZE`

### Кодировка
- Все файлы в UTF-8
- Добавляйте поддержку UTF-8 в main():
```cpp
#include <windows.h>
SetConsoleOutputCP(CP_UTF8);
SetConsoleCP(CP_UTF8);
```

### Заголовочные файлы
- Всегда используйте include guards:
```cpp
#ifndef FILENAME_H
#define FILENAME_H
// код
#endif
```

### Форматирование
- Отступы: 4 пробела
- Открывающая скобка на той же строке
- Пробелы вокруг операторов

Пример:
```cpp
if (condition) {
    doSomething();
}
```

- ❌ Нарушение стиля кода

## Процесс Review

1. Автоматическая проверка (если настроена)
2. Ревью кода мейнтейнером
3. Обсуждение и правки (если нужно)
4. Merge в main ветку
